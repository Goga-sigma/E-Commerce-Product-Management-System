E-Commerce Product Management System

Project Overview

The E-Commerce Product Management System is a Java-based console application designed to manage products in an online store.

Features

- Add new products
- View all available products
- Search products by ID or category
- Sort products by price (low to high)
- Update product stock
- Store product details using file handling
- Automatically load and save product data

Technologies Used

- Java
- HashMap
- ArrayList
- Collections Framework
- File Handling

Concepts Implemented

- Object-Oriented Programming
- Searching and Sorting
- Java Methods
- Exception Handling
- File Input/Output

How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java file:

javac ECommerceProductManagement.java

5. Run the application:

java ECommerceProductManagement
